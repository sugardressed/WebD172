# WEBD 172 Week 5 Task Manager

A React-only task manager for the Week 5 React review.

## Concepts demonstrated

- Function components
- JSX
- Props
- `useState`
- Controlled form input
- Event handlers
- Rendering arrays with `map()`
- Conditional rendering
- Add, complete, and delete tasks
- Local React state only

## Run the project

```bash
npm install
npm run dev
```

The tasks are stored only in React state, so refreshing the page resets the application.
