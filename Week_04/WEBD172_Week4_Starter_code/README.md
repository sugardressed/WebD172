# WEBD 172 - Week 4 Course Portal

This project combines the major Node.js and Express concepts from Weeks 3-4.

## Setup
1. Open the project folder in VS Code.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

## Routes
- `/` - static home page
- `/about` - HTML generated by Express
- `/api/courses` - all courses as JSON
- `/api/courses/:id` - one course by route parameter

## Concepts
Node.js, npm, package.json, Express, middleware, static files, routes, HTML responses, JSON responses, route parameters, status codes, fetch(), async/await, and destructuring.
